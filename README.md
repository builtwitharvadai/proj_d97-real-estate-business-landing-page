# Real Estate Business Landing Page

A professional, modern landing page for a real estate business designed to establish a strong online presence and provide essential contact information to potential clients. Built with semantic HTML5, modern CSS, and vanilla JavaScript for optimal performance and accessibility.

## 🏢 Project Overview

This landing page serves as the digital storefront for a real estate business, showcasing services, team expertise, and providing easy contact methods for prospective clients. The design emphasizes professionalism, trust, and user experience while maintaining fast load times and excellent accessibility scores.

### Key Features

- **Responsive Design**: Fully responsive layout that works seamlessly across desktop, tablet, and mobile devices
- **Semantic HTML5**: Proper use of semantic elements for better SEO and accessibility
- **Performance Optimized**: Minified CSS/JS, optimized images, and lazy loading for fast page loads
- **SEO Ready**: Comprehensive meta tags, structured data, and sitemap for search engine optimization
- **Accessible**: WCAG 2.1 compliant with proper ARIA labels and keyboard navigation
- **Modern UI/UX**: Clean, professional design with smooth animations and intuitive navigation
- **Contact Forms**: Easy-to-use contact forms with client-side validation
- **Service Showcase**: Dedicated sections highlighting real estate services and expertise

## 🛠️ Technology Stack

- **HTML5**: Semantic markup with accessibility attributes
- **CSS3**: Modern styling with Flexbox/Grid, custom properties, and animations
- **JavaScript (ES6+)**: Vanilla JS for form validation, lazy loading, and interactions
- **Build Tools**: 
  - `clean-css-cli` - CSS minification
  - `terser` - JavaScript minification
  - `html-minifier` - HTML optimization
- **Development Tools**:
  - `serve` - Local development server
  - `html-validate` - HTML validation
  - `htmlhint` - HTML linting
- **Deployment**: GitHub Pages (static hosting)

## 📋 Prerequisites

- Node.js >= 18.0.0
- npm (comes with Node.js)
- Modern web browser (Chrome, Firefox, Safari, Edge)
